# Yono Music 1.5.0-preview.2 — embedded engine Search

Karisyono · Yono Music Preview · com.yonzmusic.app.dev · code11 · Room schema3. Existing Dev debug certificate retained. Installs beside official1.4.2 or upgrades the matching Dev preview. The production application ID/key and official/latest release remain unchanged.

Online Search now executes read-only flat metadata search through embedded yt-dlp, automatically after typing, with no user API key. Separate bounded workers avoid the acquisition serial lock; lazy Python startup is shared safely by all bridges. Query cancellation/deadline, bounded cache/history, stable result IDs, limited pagination and explicit channel/artist distinction remain. Search writes no audio or Room collection rows. It preserves actual supplied metadata and thumbnail URLs, not fabricated album/artist/HD cover information.

iTunes search/clips/branding assets, the Google YouTube Data API/key form and the embedded WebView player are removed. The underlying source still is YouTube via yt-dlp's search extractor. Listening opens the original source externally; this revision offers no replacement in-app streaming audition. Selected exact URLs go to the existing download review, retaining authorization, output choice, original format and validation. Search does not promise all results downloadable or grant rights/source permission. Existing Commons/import/download capabilities remain in their consolidated flow.

SDK min26, target/compile35; JDK17, Gradle8.11.1, AGP8.9.1, Kotlin2.1.20, Media3 1.6.1.64-bit arm64-v8a/x86_64. Existing pinned CPython/Chaquopy/yt-dlp/EJS/QuickJS dependencies unchanged. Flat search does not require JS/EJS or FFmpeg. No new dependency, server, API credential, broad-storage access, database migration or manifest permission. Permissions remain INTERNET, ACCESS_NETWORK_STATE, POST_NOTIFICATIONS, WAKE_LOCK, FOREGROUND_SERVICE, FOREGROUND_SERVICE_MEDIA_PLAYBACK, FOREGROUND_SERVICE_DATA_SYNC, REQUEST_INSTALL_PACKAGES.

Preview assembly/lint,126 JVM tests,166 Python host tests and eight distinct Android fixture/regression cases passed (one test-harness correction/rerun, fully documented). Actual UI states inspected and exact Dev10→11 collection retention verified. **Live search requests failed**: host proxy CONNECT403 and Android source-network failure. This is an experimental preview with remote availability unverified, not a stable remote-search endorsement. No bypass, physical HyperOS, new live audio acquisition, or Play Protect approval claim. TEST_REPORT.md contains raw evidence and limitations.

The source snapshot precedes publication. Distribution includes actual APK size/hash/certificate and exact source commit. Publish only as prerelease v1.5.0-preview.2 with make_latest=false; no stable update.json is supplied and existing tags/releases must not be overwritten.
