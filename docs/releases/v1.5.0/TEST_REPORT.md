## Playlist and preload verification

The host playlist reader tests exact ordered IDs, canonical share/watch URLs, rejected unsafe/dynamic/ambiguous URLs, unavailable/duplicate counts, cancellation, complete-iterator/count checks and rejection rather than silent truncation above500entries. The actual Android Python bridge reads this same reader through a scoped test extractor and never downloads audio. Native Room edits exercise concurrent appends without lost updates, duplicate rejection, rename, identity-based move/removal, repeated stale removal safety and failed-edit rollback while local tracks/memberships remain untouched. References survive a fresh repository instance. JSON/backup contracts validate IDs, names, bounds and canonical metadata; no expiring audio URL is exported. A complete collection-backup export/restore with online lists was not separately exercised through SAF.

StreamResolutionCacheTest checks same-ID extraction coalescing, cancellation isolation, expiry/format acceptance, bounded LRU, invalidation and failure recovery. Native StreamPreloadTest plays a persisted online collection through the real ViewModel/MediaSession, observes next-item audio bytes arriving while the first item is still current, then advances into decoded playback without inserting local tracks. JSON records actual byte counts/transition time. Those timings are fixture/software-emulator results, not real CDN or phone latency. Five seconds is the Media3 preload target; extractor/read chunks may exceed it. Analysis is limited to two upcoming active-queue items; recent history is not crawled and restored context never autoplays. Slow networks/source expiry can still buffer.

## Security and remaining limits

Exact Maven/PyPI OSV review found GHSA-xxph-c9ww-hj94 / CVE-2026-102554 in Guava33.3.1-android. Although application source does not deserialize untrusted native Java objects, Guava was upgraded to the published fixed33.7.2-android and license/source provenance updated. The patched107-package OSV lookup returned0matches at its recorded timestamp. This is an advisory lookup, not a comprehensive native-library audit/security certification. No exploit PoC was executed. Static APK signature/manifest/native alignment results accompany the release; source credential-pattern scanning found no private key/token. Spotify OAuth UI/callback/token exchange is removed and obsolete local credentials retired; local music and metadata exports remain intact.

No independent Play Protect/external scanner, Bluetooth/headset hardware, long-duration screen-off streaming, physical storage-disconnection matrix or every extractor/container test. No crossfade, ReplayGain, synchronized lyrics or custom DSP claim. Online collection edits are local snapshots, not account synchronization. No required account, whole-storage scan, MP3 conversion/bitrate upscaling, FFmpeg, DRM/access bypass or hidden tracker. Original audio/metadata/.cover, local favorites/playlists/history, application ID, schema and signing are preserved.
