# Changelog

## 1.0.0 — Initial native Android release

- Original Yon'z geometric sound/Y brand, dark charcoal and ivory light design systems.
- Offline MediaStore/SAF library, embedded artwork, album/artist/folder browsing and local search.
- Media3 background audio session, persistent mini-player, Now Playing, seek, shuffle/repeat and editable queue.
- Room playlists, favorites/recent history, DataStore preferences and paused playback context restoration.
- Native TXT/CSV/JSON/M3U list matching, duplicate/invalid/unmatched reporting and import history.
- Playlist ordering/export, session sleep timer, system equalizer handoff and accessibility preferences.
- Minimal read-only storage access, no accounts, ads, trackers, or network permission.
- Native rewrite of safe legacy management concepts; Python/downloader/mutating migration code excluded.
