- **104 JVM tests pass**: previous 94 plus ten metadata precedence/hash/Smart Mix/listening qualification cases. Debug + AndroidTest builds and release lint pass. Release lint reports **0 errors, 107 warnings** (mostly KTX/dependency/vector guidance and intentional durable updater preference commits); the API-33 monochrome icon is present in its qualified resource despite the fallback-resource warning. Passing lint is not a zero-warning claim.
- **Existing-install in-place upgrade:** `adb install -r` replaced Dev code 5 with code 6 using the same certificate, migrated actual schema 2→3 and opened the app. All 15 pre-existing track IDs, 13 playlists, 18 ordered memberships and 2 history keys/timestamps survived. - **Native artwork cache:** requested thumbnail/large sizes, revision invalidation, intrinsic small-image dimensions and retry after the two-second negative-cache TTL.
- **Native shared MediaSession:** moved URI rebind retains ID, 3-second paused position and qualified play count. A short tap and paused seek do not count; real elapsed playing qualifies once. The initial harness issued seek against an asynchronous queue replacement and timed out; specifying queue/start position atomically passed. The failed run is retained alongside its successful recheck.
- **Native download fixtures:** real bundled Python/yt-dlp/EJS/QuickJS runtime, own MP3 over loopback, real-byte cancellation, safe tags/art/native probe, legacy queue retry/order/cancel/reuse, and original WebM/Opus publication/cover/rescan/native ExoPlayer playback pass. No new direct public-service audio transfer is claimed in this update.
- **Dependency lookup:** unchanged 96 resolved Maven packages plus all nine pinned PyPI packages (read from the current lock file) were queried against OSV: 105 queries, zero advisory matches. Native libraries and external classifications remain outside that result; absence of OSV matches is not a security guarantee.

**27 distinct Android instrumentation checks pass across the full regression and focused rechecks.** The 27-case run passed 26 and failed the empty-Home text lookup: Compose virtual nodes require traversal rather than the provider text-search API. The final playlist-creation/mapping transaction passed the focused native acquisition recovery/order check again. The source evidence records the tested candidate APK hashes. Repackaging is checked for unchanged executable/resource payloads apart from that commit metadata. This is not a bit-for-bit reproducible-build or external security certification claim.

## Limits of this update's verification

Physical Xiaomi/HyperOS, Bluetooth/wired headset hardware, real removable-media removal/reinsertion, Android 35 runtime, 16-KiB device execution, very large real-library UI/scan performance, full OS process-death of an actively transferring queue, current live YouTube/Spotify OAuth/service downloads and independent Play Protect review are not verified. Restoring a new engine client and publication receipts is separately identified as fixture recovery. No broad source-support, DRM, Spotify MP3, hardware or Play Protect approval claim is made.
